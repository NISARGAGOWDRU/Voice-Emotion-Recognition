Machine learning for emotion recognition from voice/audio signals using advanced audio feature extraction.

## Demo Images

![Emotion Recognition](https://images.unsplash.com/photo-1470225620780-dba8ba36b745?w=800&q=80)

##  Features

-  Audio Feature Extraction - MFCC, spectral features
-  Deep Learning Model - Neural network classification  
-  Real-time Analysis - Process audio files
-  Multiple Emotions - Happy, Sad, Angry, Neutral, Fearful, Disgusted, Surprised

