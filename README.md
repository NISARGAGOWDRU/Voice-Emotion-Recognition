#  Voice Emotion Recognition

Machine learning project for emotion recognition from voice/audio signals using audio feature extraction and classification algorithms.

##  Features

-  Audio Feature Extraction
-  Deep Learning Model
-  Real-time Analysis
-  Multiple Emotions

##  Technologies

- Python 3.8+, TensorFlow, Librosa, NumPy, Scikit-learn

##  Quick Start

```bash
pip install -r requirements.txt
python main.py
```
